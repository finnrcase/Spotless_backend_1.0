# Repository layout and local data

The Git root is the same folder as `README.md`, `pyproject.toml`, `src/`, `web/`, `tests/` and this documentation. The GitHub remote is `https://github.com/finnrcase/Spotless_backend_1.0.git`; the working branch is `main`.

Previously, the clone lived one directory below the actual app, in `Spotless_backend_1.0/`. Its initial commit `6d2c55d` contained only `.gitattributes`, and Git did not see the parent directory's project files. The existing Git metadata and attributes were moved to the app root, preserving that history and remote rather than starting another repository or force-pushing.

Tracked files include source code, frontend templates, dependency declarations/lockfile, tests, notebooks, schemas, source registries, documentation, concise evaluation reports and API examples. `.env.example` contains variable names with blank values and is safe to track.

Credentials, `.env` overrides, virtual environments, dependency/browser/editor caches, all `data/` inputs and acquisition manifests, fitted model binaries, local observations/rules and bulky generated maps/image galleries remain ignored on this computer. They have not been deleted. The safe manifest excerpt in `examples/` demonstrates provenance without credentials, response headers or machine-specific paths. Detailed local artifacts are regenerated by the commands in the main README and continuation guide.

After cloning, create the environment with `uv sync --frozen --extra dev --python 3.13`. Source/tests/contracts are available immediately; data-dependent integration tests and application features require the documented public-data build or a copy of the existing local datasets. A Git clone does not include the roughly gigabyte-sized local data cache or claim independent unmetered accuracy.

Before future commits, use `git status --short`, inspect `git diff --cached --stat`, and verify that environment overrides/data files remain ignored. Push normally to `origin main`; do not force-push to replace remote work.
